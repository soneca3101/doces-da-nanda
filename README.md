# Doces da Nanda - Landing Page

Landing page One-Page criada a partir do portfólio PDF da Doces da Nanda.

## Conteúdo do projeto

- `index.html` - estrutura da página
- `styles.css` - layout responsivo, animações e navegação
- `script.js` - scrollspy, menu mobile e fade-in
- `assets/images/` - imagens do site extraídas diretamente do PDF
- `assets/images/originals/` - cópia das imagens únicas incorporadas no PDF, preservando os bytes/formato extraídos do documento
- `.nojekyll` - garante publicação direta dos arquivos estáticos no GitHub Pages

## Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `doces-da-nanda`.
2. Envie **todo o conteúdo desta pasta para a raiz do repositório**. O `index.html` deve ficar na raiz.
3. No GitHub, abra `Settings` > `Pages`.
4. Em `Build and deployment`, escolha `Deploy from a branch`.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Clique em `Save`.

O endereço ficará semelhante a:

`https://SEU-USUARIO.github.io/doces-da-nanda/`

Todos os caminhos de CSS, JavaScript e imagens são relativos, portanto a página está pronta para funcionar em um repositório de projeto do GitHub Pages.

## Desenvolvimento local

Você pode abrir `index.html` diretamente no navegador ou usar a extensão Live Server do VS Code.
